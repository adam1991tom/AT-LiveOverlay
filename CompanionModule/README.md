# AT LiveOverlay Companion Module v1.0.0

Development module for Bitfocus Companion. It connects to the AT LiveOverlay v3.3.1 HTTP API on TCP port 8765.

## Setup

1. Install AT LiveOverlay v3.3.1 and open **Remote control** from its tray menu.
2. Click **Enable Windows Firewall access**.
3. Install Node.js 18 or later on the Companion development machine.
4. Run `npm install` in this folder.
5. Add the folder as a local/development module in Companion.
6. Configure the presentation computer IP and port 8765.

This is a source/development module and is not yet published in the official Companion module list.
