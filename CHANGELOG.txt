AT LiveOverlay v4.0.1

- Fixed unreadable black-on-black text on the installer's Welcome/Exit/banner pages by rebuilding banner.bmp and dialog.bmp with white backgrounds.
- Fixed the "Launch AT LiveOverlay" checkbox on the installer's finish page, which previously did nothing.
- "Check for updates" now shows the current version number in the already-up-to-date message.

AT LiveOverlay v4.0.0

- Companion API now requires a per-install token (generated automatically, shown in Remote Control) instead of being open to anyone on the LAN.
- Added named scenes: save/load a full overlay layout (URLs, positions, opacity, lock/refresh state) from the tray menu or via Companion.
- Added global hotkeys: Ctrl+Alt+O (show/hide all), Ctrl+Alt+L (lock/unlock all), Ctrl+Alt+R (reload all).
- Added a Position button on each overlay toolbar for one-click snap to a corner/edge/center.
- Each overlay's hover toolbar now shows its number and name for quick identification.
- Overlays now auto-recover from a WebView2 render/browser process crash instead of going blank.
- Added log rotation so app.log/crash.log no longer grow unbounded on long-running machines.
- Added a "Start with Windows" toggle in the tray menu.
- Added an update checker with a one-click, confirmed download-and-install flow (never silent/unattended, since the app runs live during shows).
- Companion module: added per-overlay dynamic variables, an "overlay exists" feedback, a Load Scene action, a masked (secret-text) token field, and the companion/manifest.json current Companion versions require.

AT LiveOverlay v3.3.1
- Fixed the URL editor appearing briefly then hiding behind the always-on-top overlay.
- URL editor is now owned, modal, topmost, centred on the overlay, and cannot leave the app blocked.
- Click-through and toolbar state are safely restored after editing or cancelling.
- Added detailed URL-dialog logging and exception handling.

AT LiveOverlay v3.3.1

- Added MSI-owned Windows Firewall rule for Companion remote control on TCP 8765.
- Firewall rule applies to Private network profiles and local-subnet clients.
- Rule is upgraded and removed automatically with the MSI.
- Added enterprise silent-install, silent-uninstall and version-detection scripts.
- Added Action1, Intune, Group Policy and PDQ deployment guidance.
- Added SHA-256 checksum and machine-readable release-info.json generation.
- Preserved the permanent UpgradeCode and MajorUpgrade behavior.
- Companion API starts automatically with AT LiveOverlay.
