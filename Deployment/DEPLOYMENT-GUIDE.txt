AT LiveOverlay v4.2.0 - Enterprise Deployment

INSTALL (Action1 / Intune / PDQ / command line)
msiexec.exe /i "AT-LiveOverlay-v4.2.0-Setup.msi" /qn /norestart /L*v "%ProgramData%\AT LiveOverlay\Logs\install-4.2.0.log"

DETECTION
File: C:\Program Files\AT LiveOverlay\ATLiveOverlay.exe
Required version: 4.2.0.0 or newer
Or run DETECT-VERSION.ps1. Exit code 0 means compliant; 1 means missing/outdated.

UNINSTALL
Run UNINSTALL-SILENT.ps1 as LocalSystem or administrator.

FIREWALL
The MSI adds and owns the rule "AT LiveOverlay Companion" for TCP 8765 on Private profiles, limited to the local subnet. The rule is removed automatically by MSI uninstall.

AUTOMATIC STARTUP
The MSI adds an HKLM\Software\Microsoft\Windows\CurrentVersion\Run entry named "AT LiveOverlay", so the app launches automatically at sign-in for every user of the machine. This is removed automatically by MSI uninstall. Some environments restrict Run-key entries via Group Policy; if AT LiveOverlay should not auto-start on a given machine, remove that value after install.

UPGRADES
Every release keeps the permanent UpgradeCode F4D7C037-96CC-4EF5-B75A-5438F62FD8F7. WiX MajorUpgrade removes the older MSI while preserving per-user AT LiveOverlay settings.

ACTION1 RECOMMENDED WORKFLOW
1. Create one custom package named AT LiveOverlay.
2. Upload the new MSI as a new package version; do not make additional actions reference another AT LiveOverlay package version.
3. Install command: use the INSTALL command above.
4. Detection: EXE file version >= 4.2.0.0.
5. Deploy to a pilot device first, then approve the same package version for production.
6. Schedule the automation daily or at device check-in. MSI return code 3010 means success with restart requested; the app itself does not normally require restart.

INTUNE
Use Win32 app or LOB MSI. Install behavior: System. Device restart behavior: No specific action. Detection: File version as above.

GROUP POLICY
Assign the MSI under Computer Configuration > Software Installation from a UNC path readable by Domain Computers.

PDQ DEPLOY
Create an Install step for the MSI or use the silent install command above. Success codes: 0 and 3010.
